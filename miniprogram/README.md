# 沐光小程序端 · 使用说明

> 与鸿蒙 App、web 版同源的第三端形态（微信小程序）
> 数据层 `utils/mg.js` 与鸿蒙端 `CareService.ets`、web 版 `assets/app.js` 逐行对应：同一套周期到期规则、打卡逻辑、统计口径，存储换成 `wx.Storage`

## 工程结构

```
miniprogram/
├── app.js / app.json / app.wxss     入口 · 路由与 tabBar · 全局样式（设计令牌）
├── project.config.json              工程配置（appid 占位，见下方第 1 步）
├── sitemap.json
├── utils/mg.js                      数据层：到期判断 / 打卡 / 统计 / 演示种子
└── pages/
    ├── index/                       今日：按植物分组卡片 · 打卡/撤销 · 折叠 · 进度
    ├── garden/                      花园：植物增改删 · 养护计划编辑（预设+自定义）
    ├── record/                      记录：近 7/30 天完成率 · 按日分组明细
    └── settings/                    我的：提醒开关 · 清空数据 · 关于
```

## 小佳操作步骤（约 15 分钟）

### 第 1 步：注册个人小程序，拿 AppID

1. 浏览器打开 <https://mp.weixin.qq.com/> → 右上角 **立即注册** → 选 **小程序**
2. 用未注册过小程序/公众号的**邮箱**注册（QQ 邮箱即可），激活邮件里点链接
3. 主体类型选 **个人**，按提示用微信扫码完成**实名认证**（需要本人微信已实名）
4. 登录后台 → **开发** → **开发管理** → **开发设置**，复制 **AppID**（形如 `wx1234567890abcdef`）

### 第 2 步：安装微信开发者工具并导入工程

1. 下载安装**稳定版 Stable Build**：<https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html>
2. 打开工具 → **导入项目** → 目录选本 `miniprogram` 文件夹
3. AppID 选**小程序**（不要选测试号），粘贴第 1 步拿到的 AppID
   - 若之前用测试号打开过：工具右上角 **详情 → 基本信息 → AppID** 处修改
4. 点**导入**，等编译完成即可看到四页

### 第 3 步：手机预览（生成小程序二维码）

- 工具顶部点 **预览** → 用**本人微信**扫码 → 手机上打开小程序
- 这个二维码可直接截图，作为成绩表"小程序二维码"一栏的证据
- （可选）**上传**：点工具右上角 **上传** → 填版本号 1.0.0 → 后台 **版本管理** 里选**设为体验版**，可生成体验版二维码（分享给同学扫码体验）

## 验收清单

- [ ] 今日页 5 项待办：绿萝 bb 4 项（浇水已打卡）+ 龟背竹 1 项
- [ ] 点圆圈打卡：进度从 1/5 变 2/5，卡片小进度同步变
- [ ] 花园页：添加一盆植物（昵称必填，类型可自定义，如"擦叶子"）→ 今日页立刻出现新任务
- [ ] 记录页：近 7 天完成率 63.6%，近 30 天 87.1%
- [ ] 我的页：清空数据 → 今日页变空状态 → 重新打开自动恢复演示数据

## 与真机的一致性

- 演示数据与 web 版完全相同（绿萝 bb / 龟背竹 / 小仙人掌，打卡记录按"今天"动态生成）
- 到期规则 / 统计口径 / 分组折叠 / 过点标签，均与鸿蒙端一致
- 小程序端不发送系统通知（订阅消息需服务号资质），设置页以弹窗演示
