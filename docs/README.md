# design/ — 沐光 web 可交互版（原型 + web 端形态）

> 沐光 · 植物养护助手 ｜ 与鸿蒙 App 同数据模型、同交互逻辑的 web 端实现
> 对应文档：`memory-bank/DESIGN.md`（视觉规范第 4 节，断点规范第 5 节）、`memory-bank/DATA_MODEL.md`

## 这是什么

四页静态原型升级而来的**真实可交互 web 应用**：数据存浏览器 localStorage，打卡、增删植物、统计全部真实生效——不是演示动画。与鸿蒙端 `CareService.ets` 的到期规则、统计口径逐行对应（见 `assets/app.js` 注释）。

## 文件对应关系

| 文件 | 对应页面 | 能力 |

| `settings.html` | P5 我的 / 设置 | 提醒开关（持久化）、测试通知（页内横幅演示）、**真实清空数据**、数据量概览 |

## 怎么看

1. **直接双击用浏览器打开** `index.html` 即可，无需服务器、无外部依赖。
2. **三档断点**（拖动窗口宽度，布局自动重排，右下角徽章实时显示档位）：
   - `sm`（< 600px）：单列 + 底部 Tab（手机形态）
   - `md`（600–840px）：双列卡片 + 左侧边栏导航（平板 / 折叠屏展开）
   - `lg`（> 840px）：左侧导航 + 内容区 + 右侧信息栏，三栏（2in1 / 桌面）
3. **首次打开自动写入演示数据**（绿萝 bb / 龟背竹 / 小仙人掌三盆，打卡记录按"今天"动态生成，任何日期打开状态都新鲜）。今日页左下角可「一键全打卡」「恢复演示数据」，方便演示与截图。
4. 数据存在当前浏览器 localStorage（键 `muguang_web_v1`）；「清空全部数据」后再次打开会重新写入演示数据。

## 与鸿蒙端的一致性

- 颜色 / 字号 / 圆角与 `common/Constants.ets`、`DESIGN.md` 一致（主色 `#3A7D6E`，卡片圆角 16，字号 24/18/15）
- 到期规则：某类养护"应做" ⟺ 不早于植物加入日，且（从未完成 或 最近完成日 + 周期 ≤ 当天）——与 `CareService.isDue()` 相同
- 统计口径：应做 = 各天到期任务之和，完成率 = 已做 / 应做——与 `CareService.adherence()` 相同，与记录页展示清单同源
- 今日清单按植物分组、>3 项默认折叠、打卡后就地刷新——与 `TodayView.ets` 改版后一致
- web 版不含系统通知（通知能力在鸿蒙端 `service/Notifier.ets`），设置页以页内横幅演示
